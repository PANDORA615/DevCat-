# DevCat — Soft 8-bit Audio Pack v3

Оригинальные синтезированные WAV, 32 kHz, mono, PCM 16-bit.
Тихие, округлые звуки без резкого шума и агрессивных пиков.

## Mascot
- cat_voice_soft_01/02/03: вариации коротких 8-битных слогов при появлении текста.
- cat_voice_question: вопрос.
- cat_voice_happy: радость.
- cat_voice_thinking: размышление.
- cat_voice_concern: мягкая реакция на ошибку.

## UI
- ui_soft_tap: мягкое нажатие.
- ui_soft_switch: вкладка.
- ui_soft_back: назад.
- ui_soft_open/close: панель.
- ui_soft_success/error: проверка задания.
- ui_soft_hint: подсказка.
- ui_soft_achievement: достижение.
- ui_soft_notification: уведомление.
- ui_soft_update: обновление.

## Реализация
- Слоги не на каждую букву: не чаще 7-10 в секунду, пропускать пробелы и знаки пунктуации.
- Варианты выбирать детерминированно или с контролируемой рандомизацией; не накладывать несколько звуков речи.
- Раздельные уровни громкости: mascot 15-25%, UI 10-20% от максимума, пользователь регулирует.
- Учитывать mute, reduced motion, focus, отключение звука, настройки доступности.
- Не воспроизводить UI-звук на каждый кадр анимации.
- В релизе проводить прослушивание на динамиках телефона, ноутбука и наушниках.
