# DevCat — комплект для проверки v5

1. Полностью распакуйте архив.
2. Откройте `preview.html` в браузере. Интернет не требуется. Звук изначально выключен; включите его кнопкой. Ручные аудиоплееры можно слушать независимо.
3. Выберите образ для рассмотрения мастера. Для анимаций нажмите «Вернуться к анимациям»; выберите клип, запустите его или листайте кадры стрелками. Фон переключается между шахматным, светлым и тёмным.
4. Кнопка «Реплика» демонстрирует движение рта вместе с текстом и мягкими слогами; «Отменить» и «Показать сразу» останавливают голос. Кнопки событий демонстрируют меню и реакции.
5. Прочитайте `docs/QUALITY_REPORT.md`: пакет имеет известные ограничения и не помечен готовым для релиза.

## Файлы

- `models/evolution/` — 6 отдельных ступеней эволюции.
- `models/costumes/` — 9 отдельных тематических костюмов.
- `animations/student/<state>/000.png` — отдельные кадры 31 состояния кота в шарфе.
- `views/student/` — 8 отдельных ракурсов.
- `animation_masters/` — сгенерированные последовательности и использованные запросы.
- `audio/` — 7 вариантов голоса и 11 эффектов интерфейса, без изменения байтов.
- `icons/app_icon.png` — отдельный мастер иконки.
- `manifests/` — назначения, тайминги, события, звук и фактическое покрытие.
- `docs/DevCat_Mascot_Senior_Spec_v5.md` — подробное ТЗ и сохранённые требования интеграции из v4.
- `references/` — две исходные картинки.
- `SHA256SUMS.txt` — контрольные суммы файлов комплекта.

15 образов — отдельные ресурсы. Анимации для всех 15 внешностей в этот проверочный комплект не входят: полный базовый набор показан для student. Внешность и состояние нельзя путать. Для каждого недостающего костюмного клипа манифест покрытия содержит `missing`.

Сначала оценивайте дизайн и читаемость, затем плавность и стабильность контуров. Высокое разрешение мастеров не доказывает соблюдение единой логической pixel-art сетки.
