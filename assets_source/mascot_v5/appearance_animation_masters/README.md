# Дополнительные покадровые анимации

14 изображений созданы генератором по исходным образам v5 по просьбе владельца.
Это дополнительные иллюстрации, а не исходные PNG из пользовательских архивов.
Исходный student и оригинальные контрольные суммы не изменены.

Каждый лист: 4 столбца × 7 строк, 28 фаз: idle 4, blink 4, talk 8,
happy 4, thinking 4, error 4. Сохраняются признаки образа: повязка пирата,
ключ инженера, посох мага, меч самурая и другие аксессуары.

`index.json` содержит переносимые пути; `export_report.json` — SHA мастеров,
прозрачные границы ячеек, постоянный размер исходной ячейки, центры столбцов,
один ground offset на клип и SHA файлов/декодированных пикселей каждого кадра.
Границы ищутся по прозрачным полосам около номинальных линий сетки; если
прозрачного промежутка нет, экспорт завершается ошибкой. Центры столбцов
измеряются только по idle и применяются ко всем строкам; кадры не центрируются
по отдельным bbox. Никакие части кота алгоритм не дорисовывает.

В runtime идут 128×128 RGBA, nearest-neighbor, alpha 0/255 (порог 192).
`productionReady=false` и `manualPixelRetouch=false`: технический экспорт и
визуальный просмотр не заменяют ручную художественную приёмку.

Воспроизведение экспорта с Pillow из `scripts/requirements-assets.txt`:

```sh
python3 scripts/export_appearance_animations.py
python3 scripts/sync_mascot_catalog.py
python3 scripts/package_appearance_animations.py
python3 scripts/verify_appearance_animations.py
```
