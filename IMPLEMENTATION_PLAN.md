# DevCat — план и фактический статус

Прочитана исходная спецификация `docs/SPECIFICATION.ru.md` и канонический `assets_source/DevCat_assets/cat_original.jpg`.

## Последовательность

1. Discovery: Flutter native editor, локальный runner, безопасное хранение, упаковка платформ. Критерий: прототип компилируется; риски описаны.
2. Вертикальный срез 0.1: локальный профиль → курс → практика → реальные тесты → сохранение → экспорт/синхронизация → продолжение. Материал и генератор работают без сети.
3. Поставка: анализатор, unit/integration/widget тесты, Linux desktop проверка, матрица сборок GitHub Actions; release только с реально собранными файлами и SHA256.
4. NOT_IMPLEMENTED: полные продвинутые курсы, LSP/DAP/PTY, пакетные менеджеры, серверный multi-tenant runner, OAuth/SSH/GitHub UI, PostgreSQL/Redis/S3/OIDC, все 59 кадров кота, ручной редактор всех токенов. Никаких имитирующих кнопок.

## Направления 0.1

Каждое направление: собственный вводный материал с источником, примерами и двумя ошибками, проверяемая практика, эталон, три подсказки. Локальный параметрический генератор для C, C++, C#, Python, Java, JavaScript, Go, SQL; Git — фиксированная учебная практика настоящего репозитория на desktop.

- [ ] C / C17 — ввод/вывод, арифметика, циклы.
- [ ] C++ / C++20 — ввод/вывод, переменные, циклы.
- [ ] C# / .NET 8 — консоль, типы, циклы.
- [ ] Python / 3 — range, отступы, сумма.
- [ ] Java / 21 — main, типы, циклы.
- [ ] JavaScript / Node — stdin, Number, циклы.
- [ ] Go / 1.22+ — fmt, переменные, циклы.
- [ ] SQL / SQLite — SELECT, фильтры, LEFT JOIN.
- [ ] Git / 2 — init/add/commit/log, проверка дерева.

## Технические решения и ограничения

- Native Flutter Material 3, редактор flutter_code_editor: IME без WebView, подсветка/undo/gutter. Полный Monaco/LSP отложен, не объявляется готовым.
- Desktop runner запускает только код владельца устройства через аргументы процесса, без shell; временный каталог, таймаут и лимит вывода. Это НЕ sandbox для чужого кода.
- Android: весь контент, генерация, прогресс, SQLite офлайн; компиляторы остальных языков не входят в APK. Нет скрытой отправки кода.
- Sync: личный HTTPS WebDAV, запись с ETag/If-Match и повторным объединением, отдельные события попыток; credentials в secure storage. Сеть используется только по действию пользователя. Проекты не синхронизируются автоматически.
- Канонический кот: временный idle на основе оригинала. Полный atlas NOT_IMPLEMENTED.
- Linux: tar.gz, deb, rpm, AppImage; Windows ZIP + setup; macOS ZIP + DMG (без Developer ID); Android APK + AAB (подпись для прямой установки, ключ не в git). Доступность определяется успешной CI-сборкой.
- Подпись macOS Developer ID и Windows Authenticode требует сертификатов владельца; магазины не настроены.

## Приёмка

- [ ] Урок → ошибка → подсказка → успех; оценка настоящим stdout/SQL, не сравнением кода.
- [ ] Прогресс и черновики переживают перезапуск; повреждённый импорт не затирает состояние.
- [ ] Слияние прогресса идемпотентно, конфликты черновиков сохраняются.
- [ ] Sync stale ETag не перезаписывает данные второго устройства.
- [ ] Темы, reduced motion, звук и громкость сохраняются.
- [ ] Нет заявления о полной реализации всего ТЗ.
