## ОС и пакеты

- Linux x86_64: Ubuntu 22.04+, Debian 12+, актуальные Fedora/openSUSE/Arch с glibc ≥ 2.35. `deb`, `rpm`, Arch `pkg.tar.zst`, `AppImage`, `tar.gz`. GTK 3, libsecret и GStreamer — зависимости ОС, в том числе для AppImage; musl/Alpine и ARM Linux не заявлены.
- Windows x64: Windows 10/11, portable ZIP и setup EXE. Для Flutter и плагинов может понадобиться Microsoft Visual C++ Redistributable 2015–2022 x64. Authenticode не настроен.
- macOS: сборка Flutter Release, DMG и ZIP; архитектуры подтверждаются `lipo` в проверке релиза. Developer ID / notarization не настроены, поэтому Gatekeeper может потребовать ручное открытие через системные настройки.
- Android: один универсальный APK arm64-v8a + armeabi-v7a + x86_64 со всеми средами. Распаковывается только соответствующий устройству образ. AAB в 0.6.0 не распространяется. Минимум Android 7.0 (API 24), target API 36 для текущего Flutter. Магазин Google Play не настроен.

Сборка пакета не доказывает проверку на реальном устройстве. Фактические результаты: [VALIDATION.md](VALIDATION.md).

## Toolchain

| Язык | Требование |
|---|---|
| C / C++ | Clang или GCC в PATH, C17 / C++20 |
| C# | .NET 8 SDK, а не только runtime |
| Python | CPython 3.10+ в PATH |
| Java | JDK 21 с `java` и `javac` в PATH |
| JavaScript | Node.js LTS |
| Go | Go 1.22+ в PATH, без скачивания модулей |
| Git | Git 2 в PATH |

На Android компиляторы включены в APK, работают без сервера и однократно распаковываются при первом запуске. Точные версии и ограничения: [ANDROID_RUNTIME.md](ANDROID_RUNTIME.md). Desktop-компиляторы устанавливаются пользователем. C# собирает только локальный проект без NuGet-источников. Go использует `GOPROXY=off`, `GOTOOLCHAIN=local`. Перед запуском локального кода пользователь даёт согласие. Это процесс с его правами, не sandbox. Не запускайте сторонний код как недоверенные серверные задания.

## Учебный маршрут 0.5

HTML/CSS редактор использует настоящий внешний браузер и локальный сервер, не эмуляцию HTML на Flutter. Сайт сохраняется в app-support/projects; обновление браузера выполняется после сохранения. Офлайн-помощник возвращает учебные объяснения и не является генеративной моделью. Универсальный APK заменяет три split-пакета, versionCode 5007 позволяет обновление с любого прежнего варианта. ARM Linux и Windows ARM native не заявлены.

Все 496 языковых лекций и 20 Git/GitHub-занятий переписаны простым языком с опорой на учебники и официальную документацию. Источники перечислены в [BOOK_SOURCES.md](BOOK_SOURCES.md). В маршруте разделены чтение, опыт и автопроверка; 198 полных примеров проверяются запуском, 125 прежних лабораторных сохранены. HTML/CSS IDE открывает файлы выбранного урока, а не общий шаблон. Ранее сохранённые позиции прокрутки не переносятся в середину переписанного объяснения.

Android сохраняет все среды внутри одного APK. Профиль `devcat-offline-compact-1` удаляет только необязательные SDK-инструменты и исходники Java; компиляторы, стандартные библиотеки и лицензии остаются. Соответствующие исходники GPL-компонентов распространяются отдельным архивом релиза.
