# Решения и риски

## ADR-001 — Flutter и нативный редактор

Flutter 3.47.8 / Dart 3.13.7, точный pubspec.lock. `flutter_code_editor` выбран для первого среза: нативный ввод, IME без WebView, подсветка, gutter, folding, undo. Прототипы: анализатор, widget-тесты desktop/mobile, Linux release. Monaco/CodeMirror через WebView, LSP, PTY и DAP не прошли необходимые платформенные прототипы и НЕ включены. Нельзя считать первый релиз полной IDE.

## ADR-002 — никакого обязательного облака

Контент включён в пакет. Генератор — детерминированная спецификация задачи: seed, условие, starter, три подсказки, эталон и набор входов. Это параметрический помощник, не LLM и не генератор произвольных тем. Нет передачи кода внешнему AI. Генератор не используется для Git.

SQLite встроен и запускается в отдельном isolate с дедлайном. Родительский isolate вызывает потокобезопасный sqlite3_interrupt через 2 секунды. Протокол ready/result/release/closed удерживает соединение живым до отключения таймера и обработчика отмены; освобождённый указатель не передаётся в FFI. Это работает и со сборками SQLite, где sqlite3_progress_handler исключён. sqlite3_limit ограничивает размер строк/SQL, столбцы и глубину выражений. Результат читается потоковым cursor с лимитом строк/объёма. Упражнения используют query_only, один SELECT/WITH, запрет файловых функций, два fixtures; семантика проверяется по строкам результата, не тексту SQL. Строки упорядочены в контракте. Офлайн-тесты открыты пользователю, скрытые тесты без сервера обещать нельзя.

Desktop: Process.start с аргументами без shell; отдельный temp, 45 с компиляция / 5 с программа, общий stdout+stderr ≤64 КиБ. Уничтожается основной процесс; ОС-песочницы и надёжного ограничения дерева процессов/памяти нет. Только собственный доверенный код владельца устройства. Android использует встроенный PRoot и ELF loader из nativeLibraryDir с локальной ABI-средой Debian, GCC/G++, .NET 8 SDK, CPython, OpenJDK 21, Node.js 22 и Go. APK содержит весь образ, установка потоковая и атомарная с проверкой SHA-256. Компиляция ограничена 120 секундами, программа — 5 секундами и 64 КиБ вывода. PTRACE_O_EXITKILL завершает трассируемые дочерние процессы при остановке загрузчика. PRoot не является защитной песочницей; код остаётся доверенным кодом владельца. Подробнее: ANDROID_RUNTIME.md.

## ADR-003 — хранение и синхронизация

App support directory, JSON snapshots через временный файл + backup; очередь записи. Черновик сохраняется с debounce и при закрытии экрана/уходе приложения; при аварийном завершении ОС возможна потеря последних 450 мс. Импорт валидируется до мутации и ограничен 5 МиБ. Записи попыток не перезаписываются; успешность выводится из объединения событий. Черновики — регистр task/device с возрастающей revision; обе версии разных устройств остаются доступны в редакторе.

WebDAV опционален и работает только по нажатию. GET → merge → durable local save → PUT If-Match. При 404 — If-None-Match: *, при 412 — повторный GET/merge. Нет сильного ETag — синхронизация запрещена. Только HTTPS; redirect запрещён для защиты Basic credentials. Пользователь указывает доверенное хранилище и пароль приложения. Пароль опционально в системном keychain; при отсутствии сервиса — только RAM. Пароль исключён из экспорта.

Ограничения: ручная синхронизация, часы устройств влияют на выбор последнего черновика/позиции, альтернативные черновики сохраняются. Для WebDAV не реализовано E2EE (администратор видит данные). Фоновая синхронизация и аккаунты не реализованы. Исходники IDE входят в drafts и передаются; внешние файлы и базы проектов — нет. Поставщик WebDAV должен корректно обеспечивать условные записи.

## ADR-004 — локальное соединение устройств

`nearby_sync.dart`: короткоживущий HTTP endpoint только для зашифрованных сообщений в LAN. QR содержит RFC1918 IPv4, порт, случайный ключ AES-256 и идентификатор сессии. Все запросы и ответы — AES-GCM с новым nonce и аутентификацией; ответ привязан к request id, повторы id отклоняются. Код действует 5 минут, сервер закрывается при уходе со страницы. Лимит передачи 8 МиБ, прогресса 5 МиБ. Адреса публичных серверов и редиректы не допускаются. Передача выполняет merge и durable save на обоих устройствах. QR — bearer secret; его нельзя публиковать.

Android разрешает cleartext транспорт для LAN, но полезная нагрузка зашифрована. WebDAV по-прежнему принудительно использует HTTPS. QR-сканер включён на Android, камера используется только на экране сканирования. На ПК — QR и вставка кода. Это соединение по запросу, без discovery broadcast, аккаунтов и фоновой синхронизации.

## ADR-005 — проекты и лекции

320 лекций собраны из авторских рукописей `scripts/curriculum.py`, `language_notes.py`, `sql_curriculum.py`, с примерами из `foundation_examples.py`. Структура включает главы, разделы, изображения, схемы, вопросы, практическую работу и критерии. 125 лабораторных имеют автоматический контракт; проектные работы явно требуют самопроверки. Общие педагогические разделы переиспользуются между языками, синтаксис и специальные темы различаются. Автоматические проверки не заменяют независимую экспертную редактуру.

`DevProject`: максимум 40 текстовых файлов / 180 КБ. Проект хранится как версионированный draft, поэтому переносит исходники и сохраняет версии разных устройств. Перед запуском валидируются пути, коллизии регистра, файл/каталог и символические ссылки. Файлы материализуются в app-support/projects/id. Манифест удаляет исключённые исходники, сгенерированные программой данные сохраняются. C/C++/C#/Java/Go собирают несколько исходников; Python и Node импортируют локальные модули. Сборки помещаются в служебный каталог. SQL имеет собственную постоянную базу, один оператор за запуск и лимиты. Произвольные созданные программой файлы и SQLite-база не включаются в sync автоматически.

## ADR-006 — логотип в цвет темы

`DevCatLogo` использует один канонический растровый исходник с цветовым преобразованием при отрисовке. Фон следует Material-палитре и яркости темы, чёрный кот и белые глаза сохраняются. Логотип установлен в боковой панели и мобильной шапке; смена цвета идёт вместе с анимацией ThemeData. Raster widget test сравнивает пиксели светлой зелёной, светлой голубой и тёмной голубой тем, проверяя неизменность силуэта. Системные значки установщиков остаются исходным брендовым вариантом.

## Регистр рисков

| Риск | Решение / статус |
|---|---|
| Чужой код имеет доступ к файлам | Только запуск собственного кода после согласия; sandbox NOT_IMPLEMENTED |
| Большие встроенные среды Android | Отдельные APK по ABI, проверка свободного места, потоковая распаковка и контрольная сумма |
| Конфликт двух устройств | ETag + события + черновики по устройствам; HTTPS integration test |
| Утрата ключа Android | Постоянный ключ вне git; владелец обязан сохранить резервную копию |
| macOS Gatekeeper / Windows репутация | Нет сертификатов владельца; неподписанные desktop-дистрибутивы |
| 60 fps, IME, screen reader на всех ОС | Требуют реальных устройств; не заявлены как измеренная гарантия |
| Устаревание курса | Ревизия и источники; автоматические примеры не заменяют экспертное ревью |
| Кот не имеет требуемого atlas | Временный idle, TODO отдельного набора проверенных кадров |

## ADR-007 — регулярный разговор кота

CompanionBar закреплён под содержимым всех основных вкладок. CatChatter перемешивает офлайн-библиотеку по месту, теме и языку без повторов до исчерпания набора. По умолчанию интервал 20 секунд, настройки 10/20/45/90 секунд. История ограничена 30 репликами. Таймер отменяется в dispose, в фоне и при выключении; модальные маршруты и текущая реакция голоса имеют приоритет. Голос подчиняется существующим master/voice/volume/style настройкам. Реплики не приписывают коту анализ пользовательского кода или успешную проверку, которой не было.
