# Пиксельный компаньон ПК 0.9.1

Новый мастер построен на общей сетке 32×32 и экспортирован в 128×128 без сглаживания. Это отдельная геометрическая отрисовка персонажа, а не уменьшение вырезок из постера. Исходный комплект v5 и его 284 контрольные суммы остаются в `packages/cat_assets/v5_review/` без изменений.

В приложении 15 эволюционных/тематических образов и кот на учебнике. Каждый имеет покой, моргание, разговор, радость, размышление, мягкую реакцию на ошибку, сонливость и сон. У ученика подготовлены 31 действие и восемь ракурсов; у кота на книге — действия без перемещения вместе с книгой. Всего 171 клип/набор ракурсов, 764 PNG-кадра. Костюм с неподготовленным дополнительным действием сохраняет собственный покой; чужой образ не подставляется.

Кадры упакованы в один ресурс `assets/mascot_pixel/frames.json`; приложение раскрывает логические PNG-ключи через AssetBundle, а OTA использует те же исходные байты кадров. Распаковка контейнера выполняется вне UI isolate.

Все новые кадры имеют настоящую прозрачность 0/255, поля не меньше четырёх пикселей, одинаковую сетку и опору (64,112). Проверяются каждый PNG, длительности и координаты рта. У аксессуаров общие привязки к голове и корпусу; шарф следует за дыханием. Нет градиентных ореолов, текста из постеров или белого прямоугольника вокруг кота.

[Редактируемые SVG, PNG и листы сравнения](DevCat-pixel-masters.zip). Сборка мастера: `python3 scripts/build_pixel_mascot.py --install-runtime`. Платформенные иконки ПК: `python3 scripts/platform_assets.py --desktop-only`. Этот флаг оставляет Android-ресурсы прежними. Изменение мастера требует повторной визуальной проверки и переподписания пакета контента.

## Поведение

`MascotPlayback` управляет приоритетами и временем кадров. Во время jump/land сохраняется одно следующее действие, после прыжка выполняется приземление. Критический результат может прервать реакцию. Старый владелец события не отменяет нового. Покой включает случайное моргание; после минуты без ввода кот засыпает. Мышь, касание и клавиатура будят его без звукового сигнала. Время background, потери фокуса и скрытого маршрута не ускоряет анимацию.

Покой и сон обновляются по границам кадров, без непрерывной перерисовки неподвижной картинки. Активные жесты используют Ticker. Одновременно работает один источник времени. Reduced motion останавливает движение; выключение звука само по себе его не отключает.

Рот — отдельный слой поверх жеста. Текст открывается целыми графемами; паузы и пунктуация закрывают рот, не перезапуская корпус и костюм. Три формы рта выбираются по появляющимся буквам. Музыкальные слоги не являются TTS или точным lip-sync человеческой речи. Семь вариантов голоса и 11 UI WAV сохранены из предоставленного Soft8Bit v3 без перекодирования. Следующий слог ждёт нативного окончания предыдущего.

Окно движения в галерее имеет собственные границы: ходьба, бег, прыжок, остановка и темп. Частота шагов связана со скоростью перемещения. У края кот останавливается; при смене костюма прежнее движение прекращается. Для образов без ходьбы кнопки движения недоступны, выбранный костюм сохраняется. Кот не ходит поверх редактора, текста или кнопок.

## События

| Ситуация | Реакция |
|---|---|
| Объяснение, чтение, размышление | explaining, reading, thinking, thoughtful |
| Ввод ответа, редактирование кода | text_typing, typing |
| Подсказка | idea |
| Верный ответ, завершённое занятие | happy, celebrating |
| Неверный ответ, техническая ошибка | failure, error — без раздражения на ученика |
| Запуск программы, задержанное ожидание, отмена | success/error, loading, waiting |
| Доступное приложение/контент, проверенный файл | notification/new, success |
| Контекстные реплики | greeting, surprised, shy, excited, sleepy |
| История самого кота о помятой книге | sad |
| Реплика о фишинговых сайтах в Git/GitHub | angry — относится к мошенничеству |
| Покой и отсутствие ввода | idle, blink, sleeping |
| Речь и окно движения | talk/слой рта; walk, run, jump, land |

Галерея позволяет отдельно проверить каждый подготовленный клип, ракурс и все 18 WAV. Эволюция по XP и косметический выбор сохраняются независимо от учебных завершений.

## Проверка

Листы светлого/тёмного фона и кадров ученика просмотрены. Автоматические проверки покрывают все размеры, alpha, границы, SVG-мастера, длительности, паузы, повтор клипа, сохранение костюма, речь во время жеста и движение в пределах окна. Рендеры настоящих Flutter-экранов со штатным Nunito находятся в `docs/screenshots/0.9.1/`.

Измерение 60/120 Гц, экранные дикторы и прослушивание на физических устройствах требуют аппаратной приёмки. Они не объявляются выполненными по результатам unit-тестов или рендеров.
