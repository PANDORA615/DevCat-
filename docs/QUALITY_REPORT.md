# DevCat 0.9.2 — интеграция пакета v5

Дата проверки: 7 ноября 2026. Версия исходников: **0.9.2+5009**.

## Реализовано

- Подключены 15 отдельных PNG внешностей, 31 клип ученика, 8 ракурсов,
  18 исходных Soft8Bit WAV и новая иконка из трёх пользовательских архивов.
  Исходные изображения сохранены без изменения; нарезки постера при запуске нет.
- Дополнительно созданы 84 клипа для остальных 14 образов: idle/blink/talk/
  happy/thinking/error, 392 отдельных PNG 128×128 с бинарной прозрачностью.
  Сохраняются мастера, SHA-256, координаты экспорта и архив с автономным просмотром.
- Сохранены оригинальные мастера, референсы, манифесты, отчёт поставщика и
  исходные SHA-256 в `assets_source/mascot_v5`.
- Старый runtime-атлас заменён отдельными PNG с nearest-neighbor и ограничением
  размера декодирования. В манифесте ракурсы отделены от списка анимаций.
- Контроллер: приоритеты, длительности в миллисекундах, pause/resume/cancel,
  jump → land → idle, корреляция асинхронного завершения, ручной шаг кадров.
- Эволюция вычисляется из реального учебного XP: 100 XP за уровень, старт с 1.
  Границы: 1–10 / 11–25 / 26–50 / 51–75 / 76–100 / 101+.
  Костюм хранится отдельно от прогресса. Для отсутствующего клипа сохраняется
  та же внешность; диагностическая галерея показывает отсутствие кадров.
- Подключены существующие реакции уроков и практики. Общий `MascotScope`
  сохраняет внешность на экранах, использующих `CatActor` / `CatPortrait`.
- Графемный вывод речи в полосе помощника, сообщениях и учебных сессиях.
  Слоги запрашиваются по видимым буквам/числам, без очереди и наложения WAV,
  с ограничением 24 запросов / 4 секунды. Фактическая частота ограничена
  длительностью WAV (240–330 мс), поэтому искусственные 7–10 слогов/с не заявлены.
- Раздельные громкости UI, голоса и достижений; mute и косметика сохраняются
  в AppStore. Убрана общая озвучка каждого pointer-up, затрагивавшая редактор.
  Принятые учебные действия и существующие конкретные события используют WAV v3.
  Возврат/закрытие маршрута и фон останавливают голос.
- `Настройки → Кот DevCat → Галерея кота`: 15 образов, клипы, пауза,
  продолжение, отмена, шаг кадров, подложки, ракурсы, отдельное прослушивание WAV.
- На карте кольцо, тело и глиф имеют единый центр; пунктир исключён из области
  круга. Геометрия проверена при масштабах текста 100/150/200%.
- Переходы вкладок включают сдвиг и fade. Посещённые страницы остаются
  в IndexedStack, скрытые страницы получают TickerMode=false.
  Повторный выбор текущей вкладки не воспроизводит switch. Reduced motion
  отключает движение и не меняет настройку звука.
- Android: raster и adaptive launcher resources; Windows: ICO; macOS: AppIcon
  asset catalog для сборки ICNS; Linux: PNG и icon name окна/пакета.
- Безопасное обновление `courses.json`: Ed25519 с закреплённым публичным ключом,
  подписанные точные байты payload, HTTPS, semver/channel/min-version,
  SHA-256 и размер, staging, переключение настройки после записи,
  проверка при запуске, last-known-good и откат без изменения прогресса.
  Пользователь видит доступность подписи и состояние настройки OTA.
- Загрузка курсов: размер, полученные байты, проценты, скорость, отмена и повтор.
  Отмена прерывает и соединение, и зависший поток; закрытие панели отменяет
  операцию. Переход active version остаётся одной завершаемой транзакцией.
  Параллельные установки одного сервиса запрещены; каждый redirect проверяет HTTPS.

## Проверки

- `python3 scripts/verify_mascot_assets.py`: 282 исходных SHA-256 совпали;
  проверены пути, длительности, 15 внешностей, 31 клип, 8 ракурсов и PCM WAV.
- `flutter pub get --enforce-lockfile`: успешно, версии зависимостей сохранены.
- Flutter 3.47.8 / Dart 3.13.7 — те же версии, что в CI репозитория.
- Unit/widget: границы эволюции, кадровое время, jump/land, пауза,
  корреляция, собственные клипы всех 15 образов, бюджет речи, пропуск/фон, геометрия карты,
  галерея 390×844 / 1280×900, существующие учебные сценарии и настройки.
- Загрузчик: прогресс по частям, отмена зависшего соединения/ответа, позднее
  завершение соединения, безопасные redirects, циклы перенаправлений, неверный
  размер и обрыв, сохранность прогресса, повтор после отмены, закрытие панели
  и отсутствие кнопки отмены во время атомарного отката.
- OTA: правильная/подменённая подпись, неверный ключ/канал, semver,
  неполные артефакты, неверный hash, установка, повреждение активного контента,
  возврат к предыдущему и сохранение прогресса. Реальные релизы не менялись.
- Снимки `docs/screenshots/v0.9.2/` получены из Flutter widget renderer
  с загруженными шрифтами и реальными PNG. Это не доказательство нативной сборки.
- Новые кадры: 14 образов / 84 клипа / 392 PNG; проверены размеры, прозрачность,
  свободные поля, изменение фаз, исходные мастера, хеши и содержимое ZIP.
- Дополнительно исправлена воспроизводимость учебного HTML/CSS: встроенный SVG
  теперь генерируется вместе с курсами из актуальной иконки. Проверка CI не должна
  оставлять незакоммиченные изменения после `write_content.py`.
- Итоговые результаты общего прогона и bundle: [MASCOT_V5.md](MASCOT_V5.md).

## Незакрытые требования и ограничения

1. **Графика не получила статус production-ready.** Исходный пакет сам
   помечен review-generated: полупрозрачность/ореолы, регистрация и пропорции
   кадров требуют ручной художественной приёмки. Новые 392 кадра экспортированы
   технически: прозрачные границы ячеек, постоянный масштаб, регистрация столбцов
   по нейтральной строке и один ground offset на клип. Это не ручная доводка;
   `productionReady=false`, `manualPixelRetouch=false` сохранены в манифесте.
2. У остальных 14 внешностей теперь есть шесть базовых клипов. Остальные 25
   действий полного контракта (например walk/jump) для них не подготовлены.
   Явный запрос такого действия показывает диагностику и idle того же кота.
   Эмоции интерфейса сопоставлены доступным happy/thinking/error. Исходный
   `coverage.json` сохранён как снимок поставки; дополнительные кадры описаны
   в `appearance_animations.json`.
3. Нет гарантии точного фонемного lip-sync или реального TTS. Рот воспроизводит
   предоставленный talk-клип; голос состоит из WAV-слогов. Некоторые старые
   экраны с мгновенным полным текстом используют одиночные голосовые реакции.
   Не все 31 состояния привязаны к реальным продуктовым событиям; они доступны
   для проверки в галерее. Общего event bus для всех подсистем пока нет.
4. Нет ручной проверки звучания на физических динамиках/наушниках и
   профилирования 60 FPS на целевых устройствах.
5. OTA выключен без закреплённого владельцем ключа. В репозитории нет
   опубликованного подписанного update manifest. Бинарные обновления идут
   через GitHub Releases и существующие установщики; автоматическая установка,
   resume загрузки, ETag/backoff и фоновое расписание не реализованы.
   Progress/cancel для каталога курсов реализованы; возобновление требует
   отдельного протокола частичной загрузки и здесь не заявляется.
   Обновляется только каталог курсов; StudyCatalog и графика поставляются
   вместе с приложением. Эти требования полного ТЗ не объявляются закрытыми.
6. Android monochrome icon требует отдельной художественной подготовки.
   ICNS создаёт Xcode из каталога; отдельный ICNS здесь не проверен.
7. Нативная Linux-сборка в этой среде остановилась на отсутствии CMake;
   также нет полного desktop development stack, Android SDK и Xcode.
   APK/Windows/macOS/Linux установщики 0.9.2 локально не собраны и не опубликованы.
   Для них используется существующая матрица GitHub Actions после проверки PR.
8. Все остальные приложения, курсы, IDE, синхронизация и исторические релизы
   сохраняют свои ограничения. Наличие картинок не доказывает выполнение
   полного исходного v4 ТЗ, вложенного в v5.
