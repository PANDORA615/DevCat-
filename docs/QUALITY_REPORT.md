# DevCat 0.9.1 — отчёт проверки исходников

Этот отчёт описывает исходники 0.9.1. Сборки и публикация подтверждаются отдельно в VALIDATION.md и материалах выпуска.

## Графика и компаньон ПК

Исходный комплект v5 сохранён без изменений: 284 файла сверяются с SHA-256. Его прежний художественный отчёт относится к оригинальным большим изображениям, а не к новому мастеру.

Для ПК подготовлена отдельная пиксельная отрисовка: 15 образов и кот на учебнике, 171 клип/набор ракурсов, 764 прозрачных кадра 128×128. Каждый образ имеет восемь основных действий, включая отдых. У ученика есть 31 действие и восемь ракурсов. SVG/PNG-мастера и листы сравнения доступны в DevCat-pixel-masters.zip. Проверяются сетка, alpha 0/255, поля, опора, файлы и длительности. Старые большие картинки больше не включены в набор ресурсов ПК. [Контракт и привязки событий](PIXEL_MASCOT.md).

Речь и жест разделены: пунктуация закрывает рот без смены костюма и сброса анимации. Подготовлены три формы рта по графемам текста. Все 18 WAV Soft8Bit v3 сохранены байт-в-байт; голос ждёт нативного окончания слога, не образует очередь. Это музыкальная речь, не TTS. Громкости UI, компаньона и достижений независимы.

Контроллер кадров поддерживает приоритет, отмену по владельцу, переход jump → land и очередь одного действия. В галерее есть ограниченная зона движения. Темп шагов связан со скоростью, у границ кот останавливается. После минуты бездействия кот засыпает, ввод будит его без звука. Background, потеря фокуса, скрытый маршрут и reduced motion останавливают часы. Костюм без дополнительного действия сохраняет собственный образ.

## Интерфейс и практика

Сохранены исправленные центры узлов карты и направление основной навигации. Вложенные уроки, IDE и настройки используют общий направленный переход; диалоги и панели — общие длительности и reduced motion. Редактор не пересоздаётся для анимации набора. Большие JSON лекций и маршрута разбираются вне UI isolate, банки задач создаются в основном isolate.

Реальные результаты IDE и практики управляют реакциями: thinking/loading, success/error/failure, waiting при отмене. Успешный запуск без автотестов предлагает сравнить вывод, а не объявляет решение верным. Отмена не проигрывает звук ошибки. Подсказки и ответы имеют отдельные реакции; раздражённая реплика относится к фишингу, а не к ошибкам ребёнка.

Новые иконки Windows/macOS/Linux используют кота на книге. В интерфейсе акценты логотипа следуют выбранной теме, чёрный силуэт и светлый контур сохраняются. [Рендеры реальных виджетов со штатными шрифтами](screenshots/0.9.1/).

## Обучение и платформы

Остаются 516 тем, 1 548 ступеней и 521 задание с запуском настоящего кода. 56 авторских изменений условий проверяются на эталоне и на неизменённом стартере. Для 136 ступеней HTML/CSS/Git доступна конкретная практика с явной самостоятельной проверкой. 516 тем используют отдельные изображения; схемы не называются фотографиями интерфейса.

ПК-пакеты комплектуются C/C++, C#, Python, Java, JavaScript, Go и SQLite. Git-лаборатория использует установленный Git, GitHub — браузер. HTML/CSS открываются в настоящем локальном браузерном предпросмотре.

Android сохраняет функции, интерфейс и ресурсы проверенной 0.8.0, меняется только общая версия до 0.9.1+11 / versionCode 5011. Все три ABI и восемь сред остаются внутри одного универсального APK. Nearby, schema прогресса и правила объединения совместимы с ПК. [Разделение платформ](PLATFORM_SCOPE.md).

## Обновления

Подключены подписанные Ed25519 пакеты курсов, кадров, WAV и цветовых тем. Проверяются ключ, совместимость, размеры, SHA-256, схемы, PNG/CRC, WAV и полнота костюмов. Сохраняются ID встроенных и уже добавленных уроков. Загрузка имеет HTTPS, ETag, докачку, отмену, ограниченный кэш и backoff. Изменения применяются после перезапуска. Первый пакет откатывается к встроенной редакции; повреждённый пакет восстанавливается без потери предыдущей копии; конфликт содержимого с тем же номером отклоняется.

Перед открытием системного установщика повторно проверяется SHA-256 и сохраняются редакторы; работающий код блокирует этот переход. Пользователь подтверждает запуск. Для переносимых форматов и Arch показан соответствующий порядок установки. Закрытый ключ не попадает в Git или CI. Публикация формирует полный пакет по исходникам и публичной подписи и проверяет подписанный индекс против всех готовых установщиков. [Механизм обновлений](CONTENT_UPDATES.md).
