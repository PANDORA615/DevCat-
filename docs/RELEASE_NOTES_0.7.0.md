# DevCat 0.7.0 — программирование сразу после установки

Исправлена причина ошибки «Установи Clang или GCC и добавь в PATH» на ПК. Компилятор C/C++ с заголовками и библиотекой C++, Python, .NET SDK, JDK, Node.js и Go теперь входят в настольные установщики и portable-пакеты. DevCat находит собственные инструменты по абсолютным путям. Ручная установка SDK, настройка PATH и дополнительные загрузки для учебного кода не требуются.

Windows-пакет включает библиотеки Visual C++, необходимые самому приложению. Linux получает свой автономный набор, macOS — отдельные среды Intel и Apple Silicon. Каждая поставка проверяется запуском полного учебного кода и запуском восьми языков через уже собранное приложение с изолированным поиском системных инструментов.

Сохраняются учебный маршрут, 1 548 занятий, подробные лекции, IDE, реплики и звуки кота, темы, проекты и синхронизация. Android остаётся одним автономным универсальным APK; versionCode 5008 и постоянный сертификат позволяют обновление с сохранением данных.

Комплектные SDK увеличивают размер настольных установщиков. Git/GitHub остаются отдельным направлением: командной лаборатории Git на ПК по-прежнему требуется Git; взаимодействию с самим GitHub нужен интернет. Запуск пользовательского кода выполняется с правами пользователя.
