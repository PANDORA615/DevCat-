DevCat 0.9.0 — доработка поведения маскота и IDE на ПК, общая версия с Android.

На Windows, Linux и macOS:

- Подготовленные анимации кота учитывают приоритет реакций. Обычное событие после прыжка ждёт приземления; критическое может прервать движение. В покое добавлено нерегулярное моргание.
- Сворачивание, потеря фокуса, скрытие экрана и reduced motion останавливают часы анимации. После возврата время из фона не вызывает скачок кадров.
- Однократный клип в галерее можно проиграть повторно.
- Кот в IDE реагирует на длительный запуск, завершение, ошибку и отмену. Быстрый запуск не оставляет зависшую реакцию загрузки. Успешный процесс предлагается сравнить с условием, без ложного утверждения о правильности решения.
- Исправлено устаревшее сообщение о ручной установке компиляторов. Полные установщики включают C, C++, C#, Java, Python, JavaScript и Go; SQLite встроена.

Android сохраняет интерфейс и функции проверенной 0.8.0, получает номер 0.9.0 / versionCode 5010. Один универсальный APK содержит три ABI и все офлайн-среды. Для обновления используется прежний сертификат; удалять приложение и прогресс не требуется. Формат прогресса и протокол синхронизации совместимы с ПК. Сборка и Android offline tests используют один зафиксированный исходный снимок.

**Это предварительный выпуск, не полное выполнение ТЗ v5.** Графика v5 остаётся предпросмотром: анимации остальных 14 образов и доводка 128×128 не завершены. Новая библиотека подписи контента и отката ещё не подключена к интерфейсу и сетевой загрузке; пользовательского OTA пока нет. Полная привязка игровых действий, сочетание жестов с речью и аппаратная приёмка остаются открытыми. Windows Authenticode и Apple notarization не предоставляются этим выпуском. Фактические результаты сборок и SHA публикуются отдельно после проверки файлов.
