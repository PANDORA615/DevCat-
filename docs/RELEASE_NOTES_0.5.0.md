# DevCat 0.5.0 — понятный учебный маршрут

Все 496 языковых лекций и 20 занятий Git/GitHub написаны заново: простое объяснение, новые слова, пример, небольшой опыт и самостоятельная работа. Материалы основаны на присланных ссылках на учебники и актуальной документации; источники указаны в уроках и docs/BOOK_SOURCES.md. Чтение, иллюстрации, код и прогресс доступны без сети.

- План курса объединяет занятия в модули, показывает текущий шаг и отдельные закладки прочитанного. Счётчик прочитанного не подменяет автопроверку задач.
- На телефоне практика начинается с условия и примера ответа; редактор и результат имеют отдельные явные вкладки. Вход берётся из реального примера. Для SQL виден результат на учебной базе.
- Добавлены 70 полных программ для основ и восемь самостоятельных SQL-опытов. Всего 198 полных проверяемых примеров. Прежние 125 лабораторных и их идентификаторы сохранены. Старые ответы остаются в своих черновиках при новой редакции вопросов.
- HTML/CSS IDE загружает точные файлы выбранного урока, сохраняя правки в отдельном проекте. Его устойчивый идентификатор позволяет продолжать ту же работу на другом устройстве.
- Android: один универсальный APK для ARM64, ARMv7 и x86_64, все восемь сред внутри, без дополнительных загрузок. Убраны необязательные SDK-инструменты F#, форматирования, контейнеров, архив исходников Java и заголовки native-addon сборки Node. Исполняемые компоненты, стандартные библиотеки, Roslyn и .NET reference assemblies сохранены. versionCode 5006, постоянная подпись та же.
- Исправлен вывод русских сообщений Java при системной кодировке, отличной от UTF-8. Удалены неиспользуемые учебные схемы; архив книг теперь сжат.

Реплики, эмоции и разговорная анимация кота, звуки, темы, QR-синхронизация и проекты сохраняются на всех платформах. Кот на главной имеет прозрачный фон. Помощник объясняет встроенные материалы и поддерживает уточнения; генеративная модель не добавлена.

В релизе: пакеты основных Linux-дистрибутивов x86_64, Windows x64, macOS universal, один Android APK, 11 учебников, соответствующие исходники GPL-компонентов и контрольные суммы. На ПК используются установленные локальные инструменты; на Android они встроены. Аппаратная плавность, физические ARM-устройства и ручной запуск Windows/macOS требуют отдельной проверки; результаты автоматических проверок опубликованы в docs/VALIDATION.md.
