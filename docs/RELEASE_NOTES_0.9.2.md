# DevCat 0.9.2 — экспериментальный предварительный выпуск

Новые модели и иконка из пакета v5, 15 образов кота, 31 исходная анимация ученика и 84 дополнительных клипа остальных 14 образов — 392 отдельных PNG. Добавлены галерея кадров/звуков, выбор внешности, синхронизация речи с talk-кадрами, графемный вывод текста, настройки звука и переходы вкладок с сохранением состояния. В загрузчике курсов появились проценты, скорость, отмена и повтор.

Это экспериментальная ветка PR #5 / #6, а не stable-релиз и не автоматическое обновление прежней ветки v0.9.1. Графика имеет статус generated_review и требует ручной художественной приёмки. У 14 образов доступны шесть базовых действий; остальные 25 действий полного контракта для них ещё отсутствуют.

## Файлы

- Windows x64: установщик EXE и переносимый ZIP.
- macOS: universal ZIP и DMG, включают arm64/x64-среды исполнения.
- Linux x64: DEB, Fedora/openSUSE RPM, AppImage, Arch и portable tar.gz.
- Android: тестовый универсальный APK для ARM64, ARMv7 и x86_64.
- Отдельный ZIP с 392 PNG и автономным просмотрщиком: распакуйте и откройте index.html.
- SHA256SUMS, отчёты проверок, SBOM, лицензии и соответствующие исходники Android-сред.

Большие размеры установщиков объясняются встроенными компиляторами и интерпретаторами. Для обычного использования достаточно одного подходящего пакета своей платформы; runtime-sources нужны для изучения/пересборки, не для установки.

## Совместимость и подпись

**Android — только тестирование.** CI не имеет постоянного ключа владельца; APK подписан временным debug-ключом. versionCode этой ветки — 5009, тогда как v0.9.1 использовал 5011. Установка поверх v0.9.1 не поддерживается; этот APK не является путём обновления предыдущей установки. Не удаляйте прежнюю установку ради теста без собственного плана сохранения данных. Для обычного обновления нужен новый APK с постоянной подписью и возрастающим versionCode.

Windows без Authenticode; macOS с ad-hoc подписью, без Apple Developer ID/notarization. Linux проверен на Ubuntu 22.04; требования системных библиотек описаны в репозитории, отдельная аппаратная приёмка каждого дистрибутива не выполнена.

OTA курсов реализован отдельным механизмом Ed25519 и выключен без закреплённого публичного ключа владельца и опубликованного подписанного манифеста. content-index.json и подписанный пакет прежней ветки v0.9.1 здесь не публикуются и не подменяются. Автоматическая установка бинарников, resume и ETag/backoff ещё не реализованы.
