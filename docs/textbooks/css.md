## 1. Что делает CSS и как подключить файл

01 · Первые шаги · С нуля

### Что сейчас научимся делать

Разобрать тему «Что делает CSS и как подключить файл» и выполнить связанный опыт с объяснением результата.

Правила оформления записываются в style.css, подключённый из head файла index.html. Сохрани изменённый файл и обнови браузерный предпросмотр. Проверяй оба файла: селектор действует только на существующий подходящий элемент.

### Новые слова без догадок

селектор — правило CSS, выбирающее элементы HTML.

### Объяснение с самого начала

HTML описывает части страницы, CSS — правила их оформления. Правило состоит из селектора и объявлений в фигурных скобках. Селектор выбирает элементы, а пара «свойство: значение» задаёт нужный вид. Например, color меняет цвет текста, а не текстовое содержание. Сначала открой готовый index.html, затем измени одно правило в style.css. Сохрани файл и обнови браузер. Видимый результат нужно связывать с конкретным свойством: одновременная замена десятка правил не помогает понять причину.

### Результат в браузере: phone

Настоящий снимок Chromium при ширине 390px. Внешним изображениям нужны соответствующие локальные файлы.

### Результат в браузере: desktop

Настоящий снимок Chromium при ширине 1080px. Внешним изображениям нужны соответствующие локальные файлы.

### Один изучаемый фрагмент

color: #245744 — основной цвет текста; фон задаётся другим свойством.

Селектор перед фигурной скобкой определяет, к чему относятся объявления. Двоеточие разделяет имя свойства и значение, точка с запятой — соседние объявления. Внутри @media сначала проверяется условие, а затем применяются соответствующие обычные правила.

Наблюдаемый смысл этого примера: Текст абзаца становится тёмно-зелёным.

Проверь по одному действию. 1. Сохрани исходный рабочий набор. 2. Найди именно приведённый фрагмент. 3. Выполни изменение ниже. 4. Сохрани и обнови браузер. 5. Сравни конкретный результат, а не только общее впечатление от страницы.

Изменение для самостоятельного опыта: Измени только цвет, затем только размер шрифта через font-size.

```css
p { color: #245744; }
```

### Файл index.html: что читает браузер

Открой в проекте index.html. Это полный документ данного опыта. Найди изучаемый элемент среди каркаса; сведения head и видимое содержимое body имеют разные задачи.

```css
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>Учебный опыт</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<h1>Один опыт</h1><p>Этот абзац меняет цвет.</p><div>Этот текст остаётся обычным.</div>
</body>
</html>
```

### Файл style.css: что меняет оформление

Открой отдельный style.css. Подключение находится в head документа. Изучаемый селектор должен соответствовать реальному элементу HTML. Файл cat.svg уже входит в учебный проект; создавать его содержимое по памяти не требуется.

```css
p { color: #245744; }
```

### Небольшой опыт перед самостоятельной работой

Повтори показанный пример, затем измени один относящийся к теме параметр. До обновления результата запиши, какие значения или видимые части должны измениться. Сравни фактический результат с этим ожиданием.

### Если результат не совпал

Видимый результат нужно связывать с конкретным свойством: одновременная замена десятка правил не помогает понять причину.

Сначала убедись, что открыт и сохранён нужный файл. Затем проверь конкретный вход и первое место расхождения с ожидаемым результатом. Ошибка подготовки среды, ошибка записи языка и неверный ответ программы имеют разные причины. Сохрани маленький пример, на котором видно расхождение, и попроси кота разобрать именно текущую тему.

### Самостоятельная работа

Измени только цвет, затем только размер шрифта через font-size.

## 3. Выбираем элементы: тег, класс и id

01 · Первые шаги · С нуля

### Что сейчас научимся делать

Разобрать тему «Выбираем элементы: тег, класс и id» и выполнить связанный опыт с объяснением результата.

Правила оформления записываются в style.css, подключённый из head файла index.html. Сохрани изменённый файл и обнови браузерный предпросмотр. Проверяй оба файла: селектор действует только на существующий подходящий элемент.

### Новые слова без догадок

тип — вид данных и правила допустимых действий с ними.

селектор — правило CSS, выбирающее элементы HTML.

### Объяснение с самого начала

Селектор p выбирает элементы по имени тега, .card — по классу, #intro — по уникальному id. Точка и решётка относятся к записи селектора, а в HTML class="card" записывается без точки. У элемента может быть несколько классов для разных обязанностей. Сначала выдели один существующий элемент и проверь совпадение имени. Потом выбери несколько однотипных карточек. Правило без подходящего элемента ничего не изменяет, даже если синтаксически записано правильно. Не делай id повторяющимся способом оформления списка.

padding: 20px — внутренние отступы между содержимым и рамкой; значение относится к одной или нескольким сторонам.

Селектор перед фигурной скобкой определяет, к чему относятся объявления. Двоеточие разделяет имя свойства и значение, точка с запятой — соседние объявления. Внутри @media сначала проверяется условие, а затем применяются соответствующие обычные правила.

Наблюдаемый смысл этого примера: Элемент с классом card получает фон и внутренний отступ.

Проверь по одному действию. 1. Сохрани исходный рабочий набор. 2. Найди именно приведённый фрагмент. 3. Выполни изменение ниже. 4. Сохрани и обнови браузер. 5. Сравни конкретный результат, а не только общее впечатление от страницы.

## 7. Размеры: px, rem, проценты и max-width

### Что сейчас научимся делать

### Объяснение с самого начала

px обозначает CSS-пиксель, rem связан с размером шрифта корневого элемента, проценты вычисляются относительно определённой базовой величины. Нельзя сказать «процент всегда от экрана»: смысл зависит от свойства и контейнера. max-width ограничивает рост, позволяя области оставаться уже на маленьком экране. Начни с ширины 100% и понятного предела. Проверь широкую и узкую область, а не только одно окно. Не смешивай width содержимого и полную видимую ширину без учёта box-sizing.

### Один изучаемый фрагмент

max-width: 60rem — верхняя граница ширины, позволяющая элементу быть уже при недостатке места.

margin-inline: auto — внешние отступы по строчному направлению; auto может участвовать в центрировании подходящего блока.

padding: 1rem — внутренние отступы между содержимым и рамкой; значение относится к одной или нескольким сторонам.

box-sizing: border-box — правило включения внутренних отступов и рамки в заданные размеры.

Селектор перед фигурной скобкой определяет, к чему относятся объявления. Двоеточие разделяет имя свойства и значение, точка с запятой — соседние объявления. Внутри @media сначала проверяется условие, а затем применяются соответствующие обычные правила.

Наблюдаемый смысл этого примера: Контент ограничен на широком экране и помещается на узком.
