## 1. Что делает CSS и как подключить файл

01 · Первые шаги · С нуля

### Новые слова и смысл действия

HTML задаёт смысл и структуру, CSS — оформление. Правило CSS выбирает элементы и задаёт свойства. В записи p { color: #245744; } p — селектор, color — свойство, #245744 — значение. Двоеточие отделяет свойство от значения, точка с запятой завершает объявление. Фигурные скобки ограничивают набор объявлений.

### Шаг 1. Подготовь файлы

Открой DevCat IDE и создай проект CSS. В дереве файлов открой index.html. Это исходник страницы. Для CSS существует отдельный style.css: подключение уже есть в head. Сохрани полный документ ниже. Пока не добавляй сетевые библиотеки, чтобы опыт оставался понятным и работал без интернета.

```css
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>Учебный опыт</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<main class="page"><h1>Моя мастерская</h1><p class="note">Учусь оформлять страницу.</p><div class="cards catalog"><article class="card item"><h2>Первый курс</h2><p>Объяснение темы.</p><button>Открыть</button></article><article class="card item">Вторая карточка</article><article class="card item">Третья карточка</article></div></main>
</body>
</html>
```

### Шаг 2. Выполни одно изменение

HTML задаёт смысл и структуру, CSS — оформление. Правило CSS выбирает элементы и задаёт свойства. В записи p { color: #245744; } p — селектор, color — свойство, #245744 — значение. Двоеточие отделяет свойство от значения, точка с запятой завершает объявление. Фигурные скобки ограничивают набор объявлений.

Найди изучаемую запись в примере. Сначала повтори её без изменений и открой браузерный предпросмотр. Затем поменяй только одно значение или один элемент. Так ты сможешь связать видимое отличие с конкретной причиной. Не меняй одновременно HTML и CSS, если выясняешь действие одного свойства.

```css
p { color: #245744; }
```

### Шаг 3. Сопоставь исходник и экран

Текст абзаца становится тёмно-зелёным.

Исходный код и изображение страницы — разные представления одного опыта. Браузер читает структуру и правила, затем рисует результат. Слова в кавычках не превращаются в магические команды: их смысл зависит от атрибута или свойства. Если результат не похож на ожидаемый, сначала проверь выбранный файл, сохранение и подключение, затем синтаксис.

Если изменилась не та область, различи padding, margin, ширину содержимого и рамку. Не нужно угадывать десятки свойств. Вернись к последнему работающему состоянию, убери лишние правила и оставь один изучаемый элемент.
