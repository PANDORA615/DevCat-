## 1. Что такое веб-страница и браузер

01 · Первые шаги · С нуля

### Новые слова и смысл действия

Браузер — приложение, которое читает HTML и рисует страницу. HTML описывает, какие части есть в документе: заголовок, абзац, ссылка, форма. Это язык разметки, а не последовательность вычислений как Python. Файл index.html — обычный текстовый файл с особым расширением. Чтобы увидеть страницу, его нужно открыть браузером, а не ожидать консольный вывод.

### Шаг 1. Подготовь файлы

Открой DevCat IDE и создай проект HTML. В дереве файлов открой index.html. Это исходник страницы. Для CSS существует отдельный style.css: подключение уже есть в head. Сохрани полный документ ниже. В HTML h1 обозначает главный заголовок, p — абзац, а class связывает элемент с CSS-классом. Видимое содержимое находится в body, сведения и подключения — в head. Служебный каркас разбирается в первых занятиях HTML; здесь он приведён целиком. Пока не добавляй сетевые библиотеки, чтобы опыт оставался понятным и работал без интернета.

```html
<!doctype html>
<html lang="ru">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1">
<title>Учебный опыт</title>
</head>
<body>
<h1>Моя первая страница</h1>
<p>Учусь вместе с котом.</p>
</body>
</html>
```

### Шаг 3. Сопоставь исходник и экран

Исходный код и изображение страницы — разные представления одного опыта. Браузер читает структуру и правила, затем рисует результат. Слова в кавычках не превращаются в магические команды: их смысл зависит от атрибута или свойства. Вернись к последнему работающему состоянию, убери лишние правила и оставь один изучаемый элемент.

## 4. Вложенность и дерево документа

01 · Первые шаги · С нуля

**Что означает изученная запись?**

Собери три страницы: описание курса, расписание и форма записи. Каждая должна иметь один главный заголовок, навигацию и понятное основное содержимое. Таблица содержит расписание, а форма — подписанные поля имени и почты. Наличие кнопки отправки ещё не означает приём заявок: явно подпиши учебный режим, пока нет обработчика.

**Что должно быть видно в результате?**

Начало самостоятельного проекта со сформулированным назначением.

**Как проверить самостоятельное изменение?**

Реализуй все три страницы с чистого листа. Проверь ссылки, клавиатуру, узкий экран, alt и подписи формы. Объясни выбор каждого тега.

### Самостоятельная работа

Реализуй все три страницы с чистого листа. Проверь ссылки, клавиатуру, узкий экран, alt и подписи формы. Объясни выбор каждого тега.
