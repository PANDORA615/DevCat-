## 1. До Git: файл, папка, сохранение и копия

01 · До первого коммита · Git / GitHub с нуля

### Что сейчас научимся делать

Разобрать тему «До Git: файл, папка, сохранение и копия» и выполнить связанный опыт с объяснением результата.

Практика команд Git выполняется на ПК в отдельной учебной папке. Действия GitHub выполняются в своём репозитории через браузер ПК или телефона. Чтение локальной теории не требует сети; сам сервис GitHub требует подключения.

### Объяснение с самого начала

Перед Git разберёмся с обычным файлом. В редакторе есть текущий текст, на диске — сохранённая версия. Нажатие сохранения меняет файл, но ещё не создаёт запись Git. Папка объединяет файлы проекта. Создай безопасную учебную папку и README.md с одной строкой. Сохрани и открой снова. Затем измени строку и сравни, где виден новый текст. Копия папки и управляемая история изменений решают разные задачи: в истории можно понять, когда и зачем появился определённый снимок.

### Действия именно этого шага

Это последовательность действий или образец текста для текущего шага. Стрелки показывают порядок; их не нужно вводить как команды терминала. Сначала найди указанный файл или раздел интерфейса.

```git
README.md → текст «Учусь»
```

### Небольшой опыт перед самостоятельной работой

Создай учебную папку. В ней создай README.md с одной строкой «Учусь». Сохрани, закрой, открой и найди ту же строку. Пока Git не нужен.

### Если результат не совпал

Нажатие сохранения меняет файл, но ещё не создаёт запись Git.

Сначала убедись, что открыт и сохранён нужный файл. Затем проверь конкретный вход и первое место расхождения с ожидаемым результатом. Ошибка подготовки среды, ошибка записи языка и неверный ответ программы имеют разные причины. Сохрани маленький пример, на котором видно расхождение, и попроси кота разобрать именно текущую тему.
