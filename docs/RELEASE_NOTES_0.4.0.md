# DevCat 0.4.0 — учимся с полного нуля

В каждом из восьми программных направлений появился обязательный вводный маршрут: что такое исходник, где ввод и вывод, как запустить программу, чем число отличается от текста, как меняется переменная, как посчитать покупку, прочитать число, выбрать ветку и проследить цикл. C, C++, C#, Python, Java, JavaScript, Go и SQL теперь содержат по 56 занятий. HTML и CSS добавлены отдельно — по 24 занятия. Ещё 20 занятий посвящены Git и GitHub. Всего 516 занятий; это учебная программа с самостоятельными проектами, а не обещание квалификации по одному факту прочтения.

- Объяснения новых слов, полные небольшие программы, разметка строк, входы/результаты, схемы и упражнения. Схемы исходника явно отделены от трассировки исполнения. Для HTML/CSS есть реальные снимки Chromium на широком и узком экране; для GitHub — настоящие страницы в браузере ПК и телефона. Картинки увеличиваются нажатием.
- HTML/CSS IDE: index.html и style.css, несколько файлов, подсветка, сохранение, настоящий браузерный предпросмотр по временному адресу 127.0.0.1. Файлы сайта сохраняются в папке проекта; браузер обновляется после сохранения. Внешние зависимости в учебном предпросмотре блокируются, сервер доступен только устройству и работает, пока приложение открыто.
- Кот на учебнике: новая пиксельная иконка на всех платформах, шесть эмоций и парные кадры рта для разговора. В главном меню нет белой подложки вокруг кота. Анимация учитывает reduced motion и останавливается после реплики. Добавлены оригинальные мягкие нажатия и шесть голосовых вариантов; исходные 14 звуков сохранены.
- «Разберём вместе»: офлайн-помощник по материалам курса с поиском вопроса, источником, контекстом уточнения и историей. Можно попросить «сначала», «по строкам», «пример», «ошибка». Это поиск и развёрнутые авторские ответы, **не генеративная LLM**. Вопросы вне учебного материала требуют уточнения; произвольные ответы не выдумываются.
- Git: редактор README и настоящие локальные команды на ПК. GitHub: пошаговая практика в своём аккаунте через браузер ПК/телефона; сеть нужна только для работы с сервисом. OAuth, автоматический push и отправка PR самим DevCat не добавлены.
- Android: **один универсальный APK** с ARM64, ARMv7 и x86_64 и всеми встроенными компиляторами. Номер 5005 выше прежних split APK, подпись та же. Большой установщик включает три среды; распаковывается только подходящая устройству. Для установки и первого запуска нужно свободное место. Desktop-компиляторы устанавливаются отдельно.
- Прежние идентификаторы, ответы и 125 автоматических лабораторных сохранены; позиция курса переносится за новые вводные занятия.

Архив учебников содержит 11 HTML-книг, Markdown, иллюстрации и шрифты. Распакуйте целиком и откройте index.html без интернета. Native-пакеты Linux/Windows/macOS, APK, источники GPL-компонентов, лицензии и SHA256SUMS публикуются вместе.
