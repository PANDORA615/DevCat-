# DevCat 0.2.0

Расширенное локальное обучение и собственная многофайловая IDE.

- 320 лекций: по 40 для C, C++, C#, Python, Java, JavaScript, Go и SQL. Теория, примеры, схемы, четыре учебные фотографии, вопросы, лабораторные и самостоятельные проекты. Всё включено в приложение.
- 125 заданий с настоящей автоматической проверкой, более разнообразный локальный генератор. Проектные работы имеют отдельные критерии самопроверки.
- Все 14 WAV из предоставленного архива: разные сигналы действий и шесть голосов кота по ситуации. Отдельная громкость голоса и выбор характера.
- Nunito с кириллицей и JetBrains Mono офлайн. Логотип подстраивается под палитру и светлую/тёмную тему. Настройки масштаба, округления и оформления лекций.
- Синхронизация рядом: QR на компьютере → сканирование на Android; на ПК доступна вставка кода. Одна Wi-Fi сеть, без аккаунта и интернета. AES-256-GCM, временный код, объединение прогресса и версий черновиков. WebDAV доступен в дополнительном разделе.
- DevCat IDE: проекты и дерево файлов, вкладки, создание/переименование/удаление, поиск/замена, переход к строке, горячие клавиши, локальная сборка нескольких исходников и импорт модулей. Экспорт/импорт проекта; исходники входят в перенос прогресса.
- Собственная постоянная SQLite-база проекта с DDL/DML; учебная база остаётся read-only.

На компьютере для C/C++/C#/Python/Java/JS/Go нужны установленные toolchain. На Android исполняется SQLite; остальные языки доступны для обучения и редактирования. LSP, пошаговый отладчик, PTY, управление внешними пакетами и фоновые аккаунты не реализованы. Синхронизация переносит исходники из редактора, но не произвольные файлы/базы, созданные запущенным проектом.

Локальные проекты выполняются с правами пользователя. Desktop-сертификаты Apple Developer ID / Authenticode не настроены. Android подписан тем же постоянным ключом, что 0.1.0, поэтому APK можно обновить поверх прежней версии. AAB предназначен для магазина; для установки используйте APK.

Linux: deb, Fedora RPM, openSUSE RPM, Arch pkg.tar.zst, AppImage и tar.gz для x86_64/glibc ≥ 2.35. Windows: x64 setup/ZIP. macOS: universal DMG/ZIP. Android: universal и три ABI APK, AAB. Сверяйте SHA256SUMS. Инструкция — README, программа обучения — docs/CURRICULUM.md.
