# Программа курсов DevCat 0.2

Восемь направлений, по 40 лекций. Материалы, фотографии и схемы входят в офлайн-приложение. Знакомство с языком не заканчивается количеством страниц: заверши проекты, объясни решения и используй документацию.

Лекции содержат теорию, разбор, примеры, практику, вопросы и критерии завершения. 127 лабораторных проверяются автоматически; остальные работы — самостоятельная реализация и самопроверка, без фиктивной автоматической оценки. Для всех уникальных эталонов лабораторных выполняется реальный запуск в CI. Независимая экспертная редактура всего текста ещё нужна.
