# DevCat 0.9.1

Обновление компаньона, интерфейсов и доставки контента на ПК. Android сохраняет прежние функции и получает общий номер версии для продолжения обучения между устройствами.

- Новый пиксельный кот: 15 эволюционных и тематических образов, кот на учебнике, 764 прозрачных кадра и редактируемые SVG-мастера. У каждого образа есть основные эмоции и отдых, у ученика — 31 действие и восемь ракурсов.
- Речь сочетается с жестами и костюмами. Пунктуация закрывает рот; все 18 оригинальных WAV сохранены. Моргание, сон после бездействия и пробуждение от ввода; отдельное окно ходьбы, бега и прыжка в галерее.
- Общие переходы уроков, IDE, настроек, диалогов и панелей, поддержка уменьшения движения. Новые иконки ПК и цвет логотипа по теме. Большие учебные JSON загружаются вне UI isolate.
- Реакции на подсказки, ввод, запуск и проверку кода. Отмена не считается ошибкой. Верный запуск предлагает сверить результат с условием.
- «Настройки → Обновления»: подписанные курсы, изображения кота, звуки и темы; SHA-256, совместимость, докачка, отмена, откат и сохранение проектов. Установщики открываются после проверки и подтверждения через механизмы ОС.
- Сохраняются 516 тем, 1 548 ступеней, подробные лекции, отдельные иллюстрации и настоящая практика. Учебные ID и формат прогресса совместимы между устройствами.

Windows и macOS: установщик/образ и переносимый архив. Linux: DEB, Fedora/openSUSE RPM, Arch, AppImage и tar.gz. C/C++, C#, Python, Java, JavaScript, Go и SQLite включены в ПК-пакеты; отдельная настройка PATH для этих сред не требуется. Git-лаборатория использует установленный Git.

Android: один универсальный APK для ARM64, ARMv7 и x86_64, все восемь сред внутри, дополнительных загрузок нет. Интерфейс и функции зафиксированы на 0.8.0; versionCode 5011 обновляет прежнюю установку с сохранением данных при прежней подписи. Синхронизация Nearby остаётся совместимой с ПК.

В выпуск включены SHA256SUMS, сведения о компонентах и лицензиях, исходники Android-сред, лекции, подписанный пакет контента и content-index.json. Целостность пакета обновления проверяется закреплённым ключом приложения; системные подтверждения установки сохраняются.

Рендеры интерфейса и подробный отчёт: docs/QUALITY_REPORT.md. Проверки на физических устройствах, измерение 60/120 Гц и экранные дикторы требуют отдельной аппаратной приёмки. Desktop Authenticode и Apple Developer ID/notarization не настроены; требования Linux-библиотек перечислены в docs/SUPPORT.md.
