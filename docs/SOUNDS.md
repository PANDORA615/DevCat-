# Звуки DevCat 0.2

Все 14 WAV из предоставленного владельцем pixel_sounds_all.zip включены без изменения аудиоданных. Общий выключатель звука и отдельные громкости интерфейса и голоса доступны в настройках.

| Файл | Ситуация |
|---|---|
| 01 Soft Click | обычное нажатие |
| 02 Bubble | вкладка и выбор курса |
| 03 Glass | открытие и запуск |
| 04 Digital | ошибка |
| 05 Wood | сохранение |
| 06 Pop | переключатель |
| 07 Crystal | успешная проверка |
| 08 Retro Select | подсказка |
| 09 Voice Classic 8bit | приветствие |
| 10 Voice Cute | поддержка |
| 11 Voice Robot | размышление и подсказка |
| 12 Voice Monster | предупреждение |
| 13 Voice Magic NPC | успех |
| 14 Voice Retro Radio | объяснение |

Голос воспроизводится при новой реплике, не на каждом кадре или букве. Можно выбрать автоматическую смену всех голосов по ситуации или один любимый характер. Быстрые одинаковые касания ограничены по частоте, прокрутка не должна издавать звук нажатия. Если аудиосервис недоступен, обучение продолжает работать.

Проверка SHA-256 подтверждает, что каждый WAV совпадает с файлом из архива. Эмуляторные/визуальные тесты не заменяют прослушивание на физических устройствах.
