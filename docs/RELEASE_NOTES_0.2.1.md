# DevCat 0.2.1

Кот разговаривает на всех платформах. Android запускает все восемь языков локально.

- Постоянные реплики на Android, Windows, macOS и Linux, на каждой вкладке. Подсказки зависят от раздела и текущего урока. Шесть эмоциональных звуков, плавная смена текста, история последних 30 сообщений. Интервал 10/20/45/90 секунд; автоматические реплики и голос отключаются отдельно. В фоне разговор приостанавливается. Реплики и звуки включены в приложение, интернет не нужен. Голос — звуки персонажа, не озвучивание слов синтезатором речи.
- На Android доступны запуск, автоматическая проверка и многофайловые проекты C, C++, C#, Python, Java, JavaScript и Go; SQL выполняется встроенной SQLite. Компиляторы и стандартные библиотеки включены в APK: GCC 12, .NET 8, Python 3.11, Java 21, Node.js 22, Go 1.27. Не нужны сервер, Termux, отдельная загрузка SDK или GitHub.
- Исправлена остановка долгих запросов SQLite: используется потокобезопасный interrupt, поддерживаемый мобильной библиотекой. После отмены можно сразу выполнить следующий запрос.
- Сохранены 320 лекций, 125 лабораторных, локальная IDE, темы и синхронизация по QR в одной Wi-Fi сети из 0.2.0.

Android: три отдельных APK для arm64-v8a, armeabi-v7a и x86_64. Выберите архитектуру устройства; для большинства современных телефонов — arm64-v8a. Большой размер APK обусловлен включёнными компиляторами. При первом запуске практики образ распаковывается в закрытое хранилище приложения; требуется около 1.5–1.8 ГБ свободного места дополнительно к APK. Обновление сохраняет данные и использует тот же постоянный сертификат, что 0.1/0.2. Universal APK и AAB в этом выпуске не публикуются.

Linux: deb, Fedora RPM, openSUSE RPM, Arch pkg.tar.zst, AppImage и tar.gz для x86_64/glibc ≥ 2.35. Windows: x64 setup/ZIP. macOS: universal DMG/ZIP. Desktop требует установленных языковых toolchain; Apple Developer ID / Authenticode не настроены. Это предварительный выпуск: результаты проверки и ограничения — docs/VALIDATION.md и docs/ANDROID_RUNTIME.md. Проверка Android на эмуляторе не заменяет проверку на физических ARM-устройствах.

Локальные программы работают с правами приложения. Образ Android использует PRoot; это механизм совместимости, не изоляция недоверенного кода. Не запускайте неизвестные исходники. Исходники GPL-компонентов образа опубликованы отдельным архивом android-runtime-sources.tar; лицензии — THIRD_PARTY_NOTICES.md, состав образов — Android-runtimes.json. Сверяйте SHA256SUMS.
