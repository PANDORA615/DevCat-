# Данные и приватность DevCat 0.1

Приложение не создаёт аккаунт, не собирает аналитику, не отправляет crash reports и не обращается к AI. Уроки, прогресс, настройки и черновики хранятся локально в каталоге данных, указанном в настройках. Android backup отключён. Файлы не шифруются приложением: используйте блокировку устройства и шифрование ОС.

Синхронизация выполняется только по кнопке на вашем HTTPS WebDAV. Передаются попытки, позиции уроков и код черновиков, включая черновики мастерской. Получатель — выбранный вами сервер; его администратор может прочесть данные. Это не сквозное шифрование. Пароль передаётся по TLS и при выборе сохранения хранится в keychain ОС. Редиректы WebDAV запрещены. Учебные проекты Git не отправляются.

Экспорт содержит учебный код; перед передачей другим людям проверьте его на секреты. Пароли и адрес WebDAV в экспорт прогресса не включаются. Импорт объединяет записи.

Кнопка очистки сбрасывает активный локальный прогресс. Резервные копии и файлы экспорта сохраняются; для полного удаления локальных данных удалите весь каталог приложения. Для полного удаления синхронизированных данных удалите `devcat-progress-v1.json` из вашего WebDAV и отключите синхронизацию на остальных устройствах; иначе merge может вернуть записи. Провайдер хранилища управляет своими резервными копиями.

Универсальных юридических обещаний для всех регионов и детских аккаунтов нет: возрастные/магазинные требования должны проверяться владельцем перед публикацией в магазинах.
