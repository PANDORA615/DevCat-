# Данные и приватность DevCat 0.2

Курсы, картинки, шрифты и звуки включены в приложение. Для обучения не нужен аккаунт или внешний AI. Код не отправляется стороннему LLM. Настройки, попытки, позиции чтения, ответы, черновики и исходники проектов хранятся в каталоге приложения. Файлы запущенного проекта остаются в его локальном каталоге.

## Передача рядом

По кнопке создаётся endpoint в локальной сети и QR с временным случайным ключом. Он действует 5 минут и закрывается при уходе со страницы. HTTP содержит только AES-256-GCM ciphertext; ключ передаётся через QR или вставленный код. Обе стороны сохраняют объединённый прогресс. QR даёт доступ к обмену прогрессом, не публикуйте его. Discovery, аккаунты и внешние серверы не используются. Камера на Android нужна только для сканирования; изображения с неё не сохраняются и не отправляются.

Передаются попытки, позиции курсов и чтения, ответы, учебные черновики и исходники IDE. Настройки и пароли не передаются. База SQLite и файлы, созданные запущенным кодом, автоматически не включаются. Разные версии черновиков устройств сохраняются. Для конфликтующего проекта выберите нужную версию в IDE.

## Дополнительный WebDAV

Работает по кнопке с личным HTTPS-хранилищем. Его администратор может читать данные: E2EE этого режима не реализовано. Используются ETag и условные записи. Пароль приложения при выборе сохраняется в keychain ОС, иначе только в памяти. Редиректы запрещены; публичный HTTP для WebDAV не разрешён. Учебный Git sandbox не передаётся.

## Экспорт и удаление

Экспорт содержит учебный код; перед передачей проверьте секреты. Пароли и настройки подключения в экспорт прогресса не входят. Импорт валидирует и объединяет записи, не удаляя чужие версии.

Очистка прогресса сбрасывает активные записи. Резервные копии, исходные каталоги проектов и экспорты сохраняются. Для полного удаления удалите весь каталог приложения. Для удаления данных WebDAV очистите файл на сервере и отключите остальные устройства: последующее объединение может вернуть записи. Невозможно отозвать уже переданный экспорт.

Запущенный код работает с правами пользователя. Это локальная IDE для собственного кода, не изолированный сервер для чужих программ.
