# Локальное выполнение на Android 0.5.0

APK содержит весь набор: GCC/G++ 12.2 (C17/C++20), .NET SDK 8.0.427,
CPython 3.11, Liberica OpenJDK 21.0.13, Node.js 22.23.4, Go 1.27.3 и SQLite.
Один универсальный APK содержит все три архитектуры и все языки. HTML/CSS используют браузерный предпросмотр без отдельного компилятора. SQLite работает сразу; остальные среды
один раз распаковываются при первом запуске кода. В этот момент приложение
проверяет свободное место, SHA-256 образа и завершает установку атомарно.
Интернет, аккаунт, Termux и root на устройстве не нужны.

Выпуск содержит один универсальный APK ARM64 + ARMv7 + x86_64. versionCode 5006 выше прежних split-пакетов; сертификат прежний. Размер каждого образа около
428–490 МБ, распакованные среды около 1,16–1,39 ГБ; APK дополнительно содержит
Flutter, интерфейс и учебные материалы. Нужен запас для распаковки и проектов.
При обычном обновлении сохраняется постоянная подпись и пользовательские данные.
Загружаемые SDK и образы не являются частью QR-синхронизации.

PRoot запускается из `nativeLibraryDir` вместе со своим ELF loader. Это позволяет
не понижать target SDK и не выполнять скачанные бинарники из пользовательской
папки. Образ содержит стандартные Linux-среды той же архитектуры. Рабочая папка
проекта отображается как `/work`, аргументы передаются без shell-интерполяции.
Исходники PRoot и talloc включены в `third_party/`; соответствующие исходники
Debian-компонентов и OpenJDK размещаются рядом с установщиками в релизе.
Приложение MIT; независимые среды сохраняют собственные лицензии.

Поддерживаются запуск, ввод/вывод, автопроверка учебных задач и сборка проектов
с несколькими файлами. C# напрямую запускает Roslyn из установленного SDK с локальными reference
assemblies .NET 8 и формирует runtimeconfig. MSBuild, восстановление NuGet и
фоновые серверы сборки на Android не запускаются. Go использует локальный toolchain с
`GOPROXY=off` и `GOSUMDB=off`. Python и Node импортируют файлы проекта и
стандартную библиотеку. Браузерный DOM и дополнительные интернет-пакеты не
включены в консольный исполнитель.

Компиляция ограничена 120 секундами, исполнение — 5 секундами, вывод — 64 КиБ.
Java использует ограниченную кучу 256 МБ и два процессора; .NET/Go также получают
умеренный лимит параллелизма. Остановка загрузчика завершает трассируемые процессы
через `PTRACE_O_EXITKILL`. Сам PRoot не является защитной песочницей: собственная
программа может читать и менять доступные приложению файлы.

SQLite использует отдельный isolate и потокобезопасный `sqlite3_interrupt`.
Соединение остаётся живым до отсоединения таймера родителя, затем закрывается
после подтверждения. Обрыв запроса не зависит от наличия необязательного
`sqlite3_progress_handler` в мобильной библиотеке.

Проверки Android запускаются из обычного Flutter-приложения в эмуляторе API 35,
с отключёнными Wi-Fi и мобильными данными. Проверяется каждая уникальная учебная
эталонная программа, задания генератора, ввод/вывод, ошибки, таймаут и отмена,
Java 21 virtual threads и проекты из нескольких файлов. Проверки на физических
ARM64/ARMv7-устройствах и аппаратные замеры производительности пока не выполнены.

## Компактный профиль 0.5

Профиль `devcat-offline-compact-1` использует те же закреплённые версии. После восстановления полного SDK-кэша удаляются архив исходников JDK, заголовки Node для сборки native addons, шаблоны и необязательные инструменты SDK .NET. Языковые компиляторы, библиотеки, Roslyn и reference assemblies сохранены. Новые SHA-256 и фактические размеры находятся в `DevCat-0.5.0-Android-runtimes.json` релиза. Для обновления прежнего APK используется тот же постоянный ключ; никаких сред из сети после установки не требуется.
