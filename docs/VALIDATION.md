27 октября 2026, Flutter 3.47.8 / Dart 3.13.7. Локально: форматирование и анализатор без замечаний, 29 тестов прошли с обязательным наличием всех компиляторов.

- 320 лекций: уникальные идентификаторы, разделы, вопросы, реальное наличие четырёх офлайн-изображений, отделение проектной самопроверки от автоматической оценки.
- Все уникальные эталонные программы лабораторных исполняются: C/C++/C#/Python/Java/JS/Go и SQL. 40 seed-вариантов Python и 40 SQL также прошли реальные проверки.
- Многофайловые проекты всех семи языков: компиляция/связывание вспомогательного файла, импорт модуля; Python сохраняет настоящий выходной файл. Удалённый исходник исчезает при следующей материализации.
- SQLite IDE: создание таблицы, вставка, запрос и сохранение после повторного открытия.
- Зашифрованный LAN-обмен между двумя экземплярами: объединение попыток и разных черновиков, долговременное сохранение, отказ неверному ключу. Истёкшие QR, публичные адреса и повреждённые ключи отклоняются.
- Обновление 0.1: позиция цикла переносится в новую главу, история успехов сохранена, новые задания имеют отдельные версии идентификаторов.
- Widget flow: главная → лекция → практика → настройки → WebDAV → IDE → файл README. Размеры 1280×900, 390×844, 390×640 и 844×390, проверка клавиатуры.
- Все 14 WAV побайтово совпадают с предоставленным архивом; оба шрифта содержат кириллицу.

Нативная Linux release-сборка: проверены длинная лекция, код и схема, ошибка и успешная проверка Python, многофайловый проект с импортом (результат 43), сохранение проекта при перезапуске, настройки, QR и смена логотипа вместе с голубой/тёмной темой. Скриншоты сняты с запущенного приложения. QR-сеанс после снимка закрыт. Все пять jobs [CI 40479276785](https://github.com/PANDORA615/DevCat-/actions/runs/40479276785) завершились успешно; исходники приложения — `e7221e4e45f6f73af906ff1bcdc8280c1a093ee2`.

Пакеты проверены независимо: 320 лекций / 125 лабораторных, побайтовая целостность 14 WAV, наличие шрифтов и OFL-текстов в Linux/Windows/macOS/APK. Windows JSON совпадает логически с исходником с учётом CRLF. Проверены glibc ≤2.35 для Linux-библиотек, macOS universal x86_64+arm64 для всех шести нативных бинарников и версия 0.2.0+2.

Четыре APK подписаны тем же сертификатом `F4412CFC2567A7B33248DF99777C0D104761DD2DDA3EE7DE8FE8BAC467098BCA`: v2/v3 verified, zipalign 16KiB. Все 64-битные ELF в APK, включая QR-сканер, имеют LOAD alignment ≥16KiB. AAB прошёл jarsigner verify; self-signed/no timestamp предупреждения ожидаемы для ключа владельца. # Проверка релиза 0.1

Проверено 26–27 октября 2026. Flutter 3.47.8 / Dart 3.13.7, pubspec.lock зафиксирован.

## Автоматически

- Dart format, Flutter analyze: без замечаний.
- Прогресс: объединение попыток, сохранение успеха после неудачи другого устройства, идемпотентность, версии черновиков, отклонение повреждённого импорта, перезапуск и backup recovery.
- Настоящий HTTPS WebDAV integration test с временным TLS-сертификатом: конфликт ETag/412, повторное чтение и сохранение черновиков обоих устройств.
- Реальные программы C/C++/C#/Python/Java/JS/Go проверяются по stdout; CI требует наличия всех toolchain. C++ имя/возраст включает пустое имя, пробелы и границы возраста.
- SQLite LEFT JOIN на двух fixtures; зашитый ответ отклоняется; файловые операции и второй statement запрещены; бесконечный CTE прерывается native progress handler.
- Python бесконечный цикл завершается по таймауту; большой stdout ограничивается 64 КиБ; неверный ответ не проходит.
- Git init/add/commit: проверка HEAD и README в дереве, запрет traversal и сетевого push в учебной лаборатории.
- Widget-проверки: 1280×900, 390×844, 390×640, 844×390; главная → курс → настройки → WebDAV; маленькие экраны и клавиатура. Реальное хранение проверяется отдельными тестами, UI-тест использует MemoryStore.

Финальный успешный прогон: [Actions 40424035892](https://github.com/PANDORA615/DevCat-/actions/runs/40424035892), исходный commit `4717e843aa09de7ec6c60dad81c00d58330d48d0`. **15 тестов**, анализатор и все четыре платформы зелёные. Документационный коммит после него не меняет клиент и зависимости.

Дополнительно проверены ZIP CRC, Windows PE x64, macOS Mach-O universal (x86_64 + arm64), содержимое tar.gz и Arch PKGINFO. Собранный deb установлен в отдельном Ubuntu-контейнере, зависимости разрешились, приложение запустилось под Xvfb. RPM Fedora/openSUSE имеют отдельные runtime requirements. AppImage извлечён и запущен без FUSE в отдельном контейнере; старт renderer подтверждён. Проверка установки на настоящем Fedora/Arch/openSUSE не заявлена.

## Android и файлы поставки

- Подписаны universal APK, arm64-v8a APK, armeabi-v7a APK, x86_64 APK и AAB.
- Все четыре APK: apksigner verify успешно, одинаковый RSA-4096 сертификат; AAB: jarsigner verify успешно. Самоподписанный сертификат Android ожидаем и не требует публичного CA.
- zipalign проверен для страниц 16 КиБ. Все ELF LOAD segments в arm64/x86_64 библиотеках APK имеют выравнивание ≥16 КиБ; ZIP CRC проверен.
- 15 пакетов приложений: 6 Linux, 2 Windows, 2 macOS, 5 Android. Всего 20 release assets с SHA256SUMS, SBOM, notices, лицензией и публичным сертификатом.
- [Контрольные суммы](releases/v0.1.0-SHA256SUMS). Приватный ключ в репозиторий и Release не входит.
