## Автоматически

- Dart format, Flutter analyze: без замечаний.
- Прогресс: объединение попыток, сохранение успеха после неудачи другого устройства, идемпотентность, версии черновиков, отклонение повреждённого импорта, перезапуск и backup recovery.

- Реальные программы C/C++/C#/Python/Java/JS/Go проверяются по stdout; CI требует наличия всех toolchain. C++ имя/возраст включает пустое имя, пробелы и границы возраста.
- SQLite LEFT JOIN на двух fixtures; зашитый ответ отклоняется; файловые операции и второй statement запрещены; бесконечный CTE прерывается native progress handler.
- Python бесконечный цикл завершается по таймауту; большой stdout ограничивается 64 КиБ; неверный ответ не проходит.
- Git init/add/commit: проверка HEAD и README в дереве, запрет traversal и сетевого push в учебной лаборатории.
- Widget-проверки: 1280×900, 390×844, 390×640, 844×390; главная → курс → настройки → WebDAV; маленькие экраны и клавиатура. Реальное хранение проверяется отдельными тестами, UI-тест использует MemoryStore.

Финальный успешный прогон: [Actions 40424035892](https://github.com/PANDORA615/DevCat-/actions/runs/40424035892), исходный commit `4717e843aa09de7ec6c60dad81c00d58330d48d0`. **15 тестов**, анализатор и все четыре платформы зелёные. Документационный коммит после него не меняет клиент и зависимости.

Дополнительно проверены ZIP CRC, Windows PE x64, macOS Mach-O universal (x86_64 + arm64), содержимое tar.gz и Arch PKGINFO. Собранный deb установлен в отдельном Ubuntu-контейнере, зависимости разрешились, приложение запустилось под Xvfb. RPM Fedora/openSUSE имеют отдельные runtime requirements. AppImage извлечён и запущен без FUSE в отдельном контейнере; старт renderer подтверждён. Проверка установки на настоящем Fedora/Arch/openSUSE не заявлена.
