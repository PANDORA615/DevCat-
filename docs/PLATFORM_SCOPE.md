# Разделение выпуска 0.9.0

По уточнению пользователя новые функции, интерфейс и маскот развиваются только для Windows, Linux и macOS. Android сохраняет функции и интерфейс опубликованной 0.8.0; меняется номер выпуска, чтобы телефон и ПК оставались на общей версии.

- Общая версия: **0.9.0+10**. Android versionCode: **5010**, выше установленной 0.8.0/5009.
- `config/android-baseline.json` фиксирует проверенный исходный commit Android `786b0b31e643a3008644bd31fb228dc948d2da8d`.
- `scripts/stage_android_baseline.py` извлекает чистый снимок приложения в новый каталог и меняет только строку версии pubspec. Рабочий исходник ПК не затрагивается. Существующий каталог назначения не перезаписывается.
- И сборка универсального APK, и Android offline integration используют этот снимок. Три ABI и все офлайн-компиляторы остаются внутри одного APK. Подпись должна использовать прежний ключ.
- Синхронизация Nearby и формат прогресса schema 1 сохраняются. Версия приложения не является номером протокола синхронизации. Учебные ID и правила объединения прогресса менять несовместимо нельзя.

Это подготовка исходников и CI следующего выпуска, а не сообщение о публикации 0.9.0. Новые пакеты публикуются после проверок и сборок.
