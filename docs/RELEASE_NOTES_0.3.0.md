# DevCat 0.3.0 — подробные лекции

384 занятия по восьми языкам: **C, C++, C#, Python, Java, JavaScript, Go, SQL**. По 48 занятий от переменных до проектов и сложных задач. Более 216 тысяч слов теории, примеры кода, вычисления по шагам, таблицы, фотографии, вопросы и содержательные ответы.

- 64 новых разбора: префиксные суммы, скользящее окно, Кадане, поиск по ответу, DP, LIS, BFS и Дейкстра; SQL — gaps/islands, сессии, удержание когорт, иерархии, достижимость, реляционное деление, Парето и сверка операций.
- 56 полных алгоритмических программ проверяются настоящими компиляторами; восемь SQL-кейсов — встроенным SQLite. В каждой задаче указан контракт, крайние случаи, сложность и направления самостоятельного усложнения.
- Оглавление длинной лекции с плавным переходом, горизонтальные таблицы и раскрываемые разборы ответов. Прежний прогресс и 125 автоматических лабораторных сохранены; переписанные вопросы используют отдельные черновики.
- **DevCat-0.3.0-lectures.zip** — восемь HTML-книг и восемь Markdown-версий, шрифты и иллюстрации. Распакуйте и откройте index.html без интернета; доступна печать в PDF.
- SQL IDE теперь выполняет до 100 операторов за запуск в одном соединении: реальные транзакции, внешние ключи и откат незавершённой транзакции. Учебные запросы по-прежнему работают с защищённой базой.

Новые сложные работы предназначены для самостоятельного выполнения с разбором; они не добавляются к счётчику 125 автоматически оцениваемых лабораторных. Количество лекций не заменяет самостоятельные проекты и дальнейшее изучение документации.

Все четыре платформы получают одинаковые курсы. Android содержит все восемь направлений и компиляторы внутри ABI APK. Реплики кота, 14 звуков, настройки тем и QR-перенос продолжают работать офлайн.

Пакеты: Linux x86_64 deb / Fedora RPM / openSUSE RPM / Arch / AppImage / tar.gz, Windows x64 ZIP / setup.exe, macOS universal ZIP / DMG, Android arm64-v8a / armeabi-v7a / x86_64 APK. Android подписан постоянным ключом; обновляйте на тот же ABI. Требуется место для встроенных сред. Desktop-компиляторы устанавливаются отдельно; Windows Authenticode и macOS Developer ID/notarization не настроены.

Состав, ограничения и проверки: [README](https://github.com/PANDORA615/DevCat-/blob/main/README.md), [поддержка](https://github.com/PANDORA615/DevCat-/blob/main/docs/SUPPORT.md), [валидация](https://github.com/PANDORA615/DevCat-/blob/main/docs/VALIDATION.md). В релизе также доступны SHA256SUMS, SBOM, сертификат, лицензии, состав Android-сред и соответствующие GPL-исходники.
