# DevCat 0.6.0 — учиться по одному шагу

Теперь приложение открывает учебный маршрут. Внутри занятия — один вопрос за раз, короткое объяснение с примером, ответ, немедленная проверка и понятный разбор. Ошибочные вопросы возвращаются после других карточек; завершить занятие можно, исправив ошибки.

- **1 548 коротких занятий:** 516 тем × три ступени — знакомство, тренировка, самостоятельная работа. C, C++, C#, Python, Java, JavaScript, Go, SQL, HTML, CSS и Git/GitHub.
- Выбор ответа, ввод термина или фрагмента кода, сборка записи из блоков и предсказание результата. На самостоятельной ступени **323 тем** проверяется настоящая программа локальными средами. Первые вопросы не используют термины будущих глав.
- Дневная цель на 1/3/5 занятий, серия дней и XP. Новая ступень даёт 20 XP, повтор в другой день — 5 XP. Одна ступень в один день не дублирует награды при синхронизации.
- Интервальное повторение начинается с попытки вспомнить. Незаконченные занятия сохраняют очередь, ответы, ошибки и код; переносятся прежними средствами синхронизации.
- Из занятия можно открыть подробную лекцию, увеличить иллюстрацию, спросить кота или перейти в IDE. Все 11 книг и 125 лабораторных сохранены. Пройденный вопрос не выдаётся за сданную лабораторную или выполненный большой проект.
- Кот с эмоциями и анимацией речи, разные мягкие звуки, темы, закруглённый шрифт и настройка уменьшения движения работают в новом формате на всех платформах.

Один универсальный Android APK для ARM64, ARMv7 и x86_64 включает все восемь сред; дополнительные загрузки не нужны. Постоянный сертификат сохранён, versionCode 5007. На ПК используются установленные локальные компиляторы. В релизе также Linux-пакеты, Windows x64, macOS universal, офлайн-книги, соответствующие GPL-исходники и SHA256SUMS.

Обучение и прогресс работают без аккаунта и сервера. Для самого GitHub нужен интернет. Помощник использует авторские материалы и поиск, генеративная LLM не добавлена. Результаты и ограничения проверки: [VALIDATION.md](https://github.com/PANDORA615/DevCat-/blob/main/docs/VALIDATION.md); [правила обучения](https://github.com/PANDORA615/DevCat-/blob/main/docs/STUDY_FORMAT.md).
